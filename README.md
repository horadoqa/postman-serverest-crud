# Postman Serverest Crud

Projeto de testes de API utilizando [POSTMAN](<https://www.postman.com/>) e a API ServeRest, com foco nas operações CRUD de usuários.

## Objetivo

Praticar testes de API, validando as principais operações de gerenciamento de usuários:

- **Create:** cadastrar um novo usuário.
- **Read:** consultar usuários cadastrados e buscar um usuário específico.
- **Update:** atualizar os dados de um usuário.
- **Delete:** excluir um usuário.
- **Assertions:** validar status HTTP, mensagens e conteúdo das respostas.

## Tecnologias utilizadas

- [Postman](<https://www.postman.com/>)
- [ServeRest API](<https://serverest.dev>)

Testes via:

- [Postman](./docs/postman.md)
- [cli](./docs/postman-cli.md)

## Cenários de teste

- Cadastro de usuário.
- Consulta de usuário.
- CT02 - Cadastrar usuário
- CT03 - Lista de usuários retornada
- CT04 - Consultar usuário cadastrado
