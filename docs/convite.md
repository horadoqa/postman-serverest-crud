# Convite

Novo projeto de QA Automation no GitHub!

Estou desenvolvendo o ServeRest CRUD com Postman, um projeto de automação de testes de API utilizando Postman e JavaScript.

O objetivo é validar as principais operações de gerenciamento de usuários (CRUD), autenticação e contratos de API, aplicando boas práticas de automação e validação de respostas HTTP.

O que você encontrará no projeto?

- Testes de API utilizando Postman.
- Operações de Create, Read, Update e Delete (CRUD).
- Testes de autenticação.
- Validação de contratos e estruturas JSON.
- Asserções de status HTTP, mensagens e consistência dos dados.
- Uso de variáveis de ambiente e scripts JavaScript para reutilização e manutenção dos testes.
- Organização de Collections para facilitar a execução dos cenários de teste.


O projeto é um template para quem deseja iniciar ou evoluir sua jornada em Qualidade de Software, explorando a automação de testes de API com Postman.

🔗 Confira o repositório no GitHub: https://github.com/horadoqa/postman-serverest-crud

Este projeto ainda tem pontos de melhoria e pode evoluir para atender a cenários mais complexos e escaláveis. É apenas um START, com muito espaço para aprendizado, colaboração e evolução contínua!
